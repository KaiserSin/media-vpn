# Media Test 10: исходник установщика Mac

**Подключаешь новый Mac? Открой [пошаговую инструкцию](../../docs/macos-setup.md).** В ней описано получение приватного пакета, установка, исключения Happ и проверка интернета. Ниже — техническое описание установщика.

Исходник установщика Media Test 10 для macOS Apple Silicon, обновлённый 23 октября 2026 года для приватного bootstrap и исправленного cursor framing. Здесь находятся только `install.py`, оболочка явного запуска `install.command` и справочный шаблон LaunchAgent. Бинарника адаптера, профиля Happ, списка документов, ключа и живого bootstrap нет. Установщик из этого каталога не запускался при подготовке архива. Фактическое обновление существующего Mac выполнено отдельным инструментом с резервным восстановлением; результат описан в [отчёте](../../docs/status-2026-10-23.md).

## Зависимости и приватный пакет

Нужны macOS на Apple Silicon (Mach-O arm64; Intel не поддерживается), уже установленный Python **3.9+**, обычный вошедший пользователь macOS, Happ и доступ к согласованным десяти Яндекс Документам. Сторонних Python-пакетов нет. Используются штатные `/bin/launchctl`, `/usr/bin/plutil`, `/usr/sbin/lsof`, `/usr/sbin/sysctl`. Оболочка не вызывает установку Python, Homebrew или Xcode и не требует `sudo`.

Для реальной установки оператор отдельно формирует **приватную** папку вне репозитория с файлами:

| Файл | Требование |
|---|---|
| `install.py`, `install.command` | Исходники из этого каталога. |
| `media-adapter-msr` | Доверенная сборка актуального кода для Darwin arm64; в Go-исходниках нужны Go 1.26.4 и зависимости из `go.mod`/`go.sum`. Установщик проверяет формат Mach-O arm64, но не происхождение или подпись сборки. |
| `documents.urls` | Согласованный с сервером список ровно десяти приватных ссылок документов. Старый установленный набор при обновлении должен совпадать. |
| `stream-relay.key` | Ровно 32 двоичных байта, тот же ключ, что у серверного stream relay. |
| `bootstrap.json` | Приватный браузерный захват конфигураций редактора: `schemaVersion: 1`, массив `documents` из десяти записей с `url`, `editorUrl`, `clientConfig`. Точное множество `url` должно совпадать с `documents.urls`; порядок не важен. В `clientConfig.officeActionData` нужны объект `editor_config` и строка `balancer_url`. Файл до 16 MiB, принадлежит текущему пользователю, права `0600`. Cookies в пакет не входят. |
| `Media Test 10.json` | Объект полного Xray JSON для Happ с внутренним защищённым соединением к origin через локальный SOCKS и исключениями служебного трафика документов/DNS. Профиль генерируется отдельно из приватных данных; сам установщик не проверяет его сетевую маршрутизацию. |

Нужна актуальная сборка с `--doc-bootstrap-file` и исправлением cursor framing: префикс cursor должен указывать фактическую длину декодированных байтов. Код также сохраняет поддержку нескольких клиентов от 10 сентября и исправление reconnect от 13 сентября. Старый бинарник с постоянным префиксом `18` для этого пакета не подходит. Бинарники в репозиторий не включены; их происхождение и совместимость с сервером проверяются отдельно.

Все одновременно работающие на общих документах клиенты должны поддерживать несколько устройств. Старый клиент может сбрасывать чужие соединения. Это реализация для Mac с локальным адаптером; один импорт JSON в мобильный Happ такую службу не создаёт.

## Поведение установщика

Действие начинается только при явном запуске `python3 install.py` в приватной папке пакета либо открытии `install.command`. При импорте `install.py` установка не запускается. Без перечисленных входных файлов preflight завершится ошибкой до установки.

Файлы размещаются относительно домашнего каталога текущего пользователя: `~/Library/Application Support/Media Test 10/`; LaunchAgent — `~/Library/LaunchAgents/local.media.document-pool.plist`. Установщик создаёт приватную резервную копию заменяемых файлов и состояния службы, включая bootstrap, проверяет plist, запускает адаптер и при неуспехе пытается восстановить прежние байты, права и состояние службы. При обновлении старой установки `bootstrap.json` может отсутствовать: это допустимо, а откат удалит новый файл. Набор документов и ключ должны совпадать с установленными. Секреты/журналы получают права `0600`, каталог — `0700`.

Адаптер слушает `127.0.0.1:19180`; минимальная готовность — десять документов, тайм-аут старта — 120 секунд, ожидание установщика — до 135 секунд. Параметры stream: блок **1024 байта**, окно 4194304 байта, интервал повтора 5 секунд, 128 потоков, очередь 128 пакетов на канал, статистика каждые 15 секунд. LaunchAgent запускается при входе, перезапускает неуспешно завершившийся процесс и ограничивает частоту запусков интервалом 60 секунд.

LaunchAgent передаёт `--doc-bootstrap-file` к установленному `bootstrap.json`. Блок 1024 байта вместе с 68-байтовым заголовком даёт cursor payload 1092 байта. Такой размер выбран по испытаниям текущего сервиса: большие cursor сообщения могут отбрасываться при успешной аутентификации.

Установщик не импортирует профиль в Happ и не включает VPN. После успешной локальной установки профиль импортируют вручную на том же Mac. Локальный SOCKS и подключение к документам не подтверждают трафик через VDS или обход белых списков.

## Срок жизни bootstrap и ручное обновление

Bootstrap содержит подписанные editor-конфигурации, которые могут истечь или быть отозваны; серверные сессии также имеют ограниченный срок жизни. Автоматического обновления браузерного захвата здесь нет. Перезапуск процесса повторно использует тот же файл и не продлевает срок действия захваченных данных.

При истечении сессии или отказе авторизации оператор получает новый разрешённый захват для тех же десяти документов, формирует приватный `bootstrap.json` и проверяет передачу между обоими peer. Для обновления Mac можно собрать новый приватный пакет с теми же `documents.urls`, ключом и профилем, затем явно повторить установку. Обновление bootstrap на сервере выполняется отдельно; этот установщик управляет только локальным Mac. Не обещается постоянная доступность сервиса или автоматическое восстановление после изменения протокола.

## LaunchAgent template

`local.media.document-pool.plist.template` воспроизводит `candidate_plist()` исходного установщика. `__USER_HOME__` — явный текстовый placeholder, который launchd сам не подставляет. Это справочный файл: не копируйте его в `~/Library/LaunchAgents` и не загружайте без подготовки приватного пакета. Рабочий plist установщик генерирует сам через `Path.home()`, что корректно обрабатывает пробелы в путях.

Архив не содержит live-state, живого bootstrap, готовых документов, ключей, cookies, серверных адресов или ссылок подписки. Приватный пакет и резервные копии установки следует держать отдельно от Git.

## Профиль Happ под нагрузкой

Короткая системная проверка прошла для отдельного профиля **Media Test 10 MUX**, где основной VLESS outbound содержит `"mux": {"enabled": true, "concurrency": 128}`. Без MUX системная нагрузка вызывала сбои, хотя единичная загрузка проходила. Этот параметр относится к профилю Xray, не к LaunchAgent. Установщик не импортирует и не изменяет профиль в Happ. Для выхода адаптера к Яндексу дополнительно требуется исключение точного IP balancer на уровне системного VPN; описание — в [инструкции bootstrap](../../docs/yandex-bootstrap.md). Длительная стабильность и работа из сети с белыми списками не подтверждены.
