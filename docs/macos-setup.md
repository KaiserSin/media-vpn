# Подключение Media VPN на новом Mac

Эта инструкция подключает новый **Mac с Apple Silicon (M1 и новее)** к уже настроенному VPN через Яндекс Документы. Для Intel текущий установщик не подходит. Сервер и десять транспортных документов должны уже работать; здесь настраивается только новый Mac.

Если приватный пакет уже получен, начинай с шага 2. На новом Mac не нужны Go, доступ по SSH к серверу или пароль от аккаунта Яндекс — актуальные настройки передаются в пакете.

## 1. Где взять приватный пакет

Нужен архив **`Media-Test-10-private.zip`** от владельца этого VPN — человека, у которого есть настроенный Mac, доступ к серверу и транспортным документам. GitHub содержит код и примеры, но не действующие ключи и настройки подключения.

Для текущего развёртывания архив подготовлен **локально на исходном настроенном Mac**, вне Git-репозитория. Его можно найти в Finder через **Переход → Переход к папке…** (`Shift + Cmd + G`):

```text
~/Documents/Codex/2026-10-23/vpn-github/outputs/
```

В этой папке лежит `Media-Test-10-private.zip`. Это путь на исходном Mac; скачивать его с GitHub нельзя. Владелец передаёт архив на новый Mac через AirDrop или свой USB-накопитель. Если архив не сохранился, в конце инструкции описана повторная сборка.

В архиве должна быть одна папка `Media-Test-10-private` с **восемью файлами**:

| Файл | Для чего нужен |
| --- | --- |
| `install.py` | Установщик адаптера. |
| `install.command` | Оболочка запуска установщика. |
| `media-adapter-msr` | Готовая сборка адаптера для Apple Silicon. |
| `documents.urls` | Десять согласованных с сервером ссылок документов. |
| `stream-relay.key` | Двоичный ключ, совпадающий с серверным. |
| `bootstrap.json` | Действующие подписанные настройки редакторов Яндекса. |
| `Media Test 10.json` | Проверенный профиль **Media Test 10 MUX**, сохранённый под этим точным именем файла. |
| `happ-excluded-routes.txt` | Адреса, которые нужно добавить в исключения Happ. |

Архив даёт доступ к VPN и транспортным документам. Храни его отдельно от исходников; не добавляй в GitHub, Issues или Releases. Если нет ни готового пакета, ни доступа к владельцу развёртывания, одних файлов этого репозитория для подключения недостаточно. Создавать новый случайный ключ вместо полученного нельзя — сервер его не примет.

## 2. Установи Happ и Python

1. В меню Apple открой **Об этом Mac** и проверь, что указан чип Apple M-серии.
2. Установи **Happ для macOS из App Store**, ссылка есть на [официальном сайте Happ](https://www.happ.su/main). Эта инструкция проверена на App Store-варианте Happ **5.7.0**; отдельная Desktop/DMG-версия может иметь другой интерфейс и настройки туннеля.
3. Установи актуальный стабильный **Python 3 для macOS** с [python.org](https://www.python.org/downloads/macos/). Минимум для установщика — Python 3.9.
4. Открой приложение **Терминал** и выполни:

```sh
python3 --version
```

Должна появиться версия Python 3.9 или новее. Если Python отсутствует или macOS предлагает установить средства разработчика, сначала заверши установку Python с python.org и открой новое окно Терминала. Сам установщик VPN зависимости не скачивает.

## 3. Распакуй приватный пакет

1. Получи `Media-Test-10-private.zip` от владельца VPN и распакуй двойным щелчком.
2. В Finder нажми **Shift + Cmd + H** — откроется домашняя папка нового пользователя.
3. Перемести туда **всю** папку `Media-Test-10-private`. Не смешивай её с папкой скачанного GitHub-репозитория.
4. Проверь восемь имён из таблицы. В частности, файл должен называться `Media Test 10.json`, без дополнительного `.txt` в конце.
5. Пока оставь Happ и другие VPN отключёнными. Для первой установки нужен обычный работающий интернет.

В дальнейших командах предполагается путь `~/Media-Test-10-private`. Имя пользователя на новом Mac может отличаться от исходного — это нормально.

## 4. Установи локальный адаптер

Вставь в Терминал весь блок и нажми Enter. Запускай от своего обычного пользователя **без `sudo`**:

```sh
(
  set -e
  cd "$HOME/Media-Test-10-private"
  chmod 700 .
  chmod 600 bootstrap.json documents.urls stream-relay.key "Media Test 10.json" happ-excluded-routes.txt
  chmod 700 media-adapter-msr install.command
  python3 install.py
)
```

Команда выставляет приватные права файлов и запускает установщик. Дождись результата: подключение к документам может занять **до 135 секунд**. Не закрывай окно во время установки.

Признак успешной установки:

```text
Media Test 10 установлен. Локальный адаптер готов: 127.0.0.1:19180.
```

Адаптер будет находиться в `~/Library/Application Support/Media Test 10/` и запускаться при входе в macOS. Этот успех подтверждает только локальный адаптер: профиль Happ и исключения ещё нужно настроить.

Если появилась ошибка, пока не включай VPN. Установщик пытается вернуть прежние файлы и состояние службы и печатает путь резервной копии. Не запускай его повторно с `sudo`.

## 5. Добавь исключения в Happ — до первого подключения

Это обязательный шаг: внешний адаптер должен подключаться к Яндексу через обычную сеть, иначе его соединение может попасть внутрь собственного VPN и интернет перестанет работать.

1. Открой `happ-excluded-routes.txt` из приватного пакета в TextEdit. Там находится один или несколько адресов, по одному на строку, с окончанием `/32`.
2. В Happ открой **Настройки** (шестерёнка). Для проверенного варианта в разделе **Туннель** переключатель **Xray TUN** должен быть **выключен**.
3. Открой **Расширенные настройки → Dev Settings → Исключённые маршруты**. В английском интерфейсе последний пункт называется **Excluded Routes**.
4. Скопируй **одну** строку из файла целиком, вставь в поле **IP-адрес** и нажми **Добавить**.
5. Повтори для всех строк. Не удаляй уже имеющиеся системные и локальные исключения.
6. Убедись, что каждый добавленный адрес появился в списке, затем вернись на главный экран.

Адреса нужно брать из своего актуального пакета. Они могут меняться; старые IP из примеров или чужой инструкции не заменяют этот список. MUX уже включён внутри подготовленного JSON — менять глобальный переключатель «Использовать Mux» для этого профиля не требуется.

## 6. Импортируй профиль в Happ

1. Открой файл **`Media Test 10.json` из приватной папки** в TextEdit: правый щелчок в Finder → **Открыть в программе → TextEdit**. Не открывай `.example` из GitHub.
2. Нажми **Cmd + A**, затем **Cmd + C**, чтобы скопировать весь JSON. Ничего в нём не редактируй.
3. Вернись в Happ. Нажми **+** и выбери добавление **из буфера обмена**.
4. Дождись сообщения **«Успешно»**. В списке должен появиться **Media Test 10 MUX**.
5. Выбери этот профиль. Наличие старых `Media Test 10`, `Media Test` или обычного `Media` не означает, что выбран нужный маршрут.

Имя файла остаётся `Media Test 10.json`, а имя профиля внутри Happ — **Media Test 10 MUX**. Это намеренно. Одного импорта JSON без установки адаптера из шага 4 недостаточно.

## 7. Включи и проверь интернет

1. Убедись, что выбран **Media Test 10 MUX**, и нажми большую кнопку подключения. При первом запуске разреши macOS добавить VPN-конфигурацию Happ.
2. Открой новый HTTPS-сайт в браузере. Затем открой [проверку Cloudflare](https://www.cloudflare.com/cdn-cgi/trace): строка `ip=` должна показывать адрес выхода VPN-сервера. Уточни ожидаемый адрес у владельца пакета; одного сообщения Happ «Подключён» недостаточно.
3. Проверь загрузку небольшого файла или обычной страницы с изображениями. В проверке от 23 октября 2026 года выход был в NL, а файл 1 МиБ загрузился примерно за 23 секунды — высокой скорости этот результат не обещает.
4. Если интернет пропал или запросы зависают, **сразу отключи Happ той же большой кнопкой**. После отключения проверь, что обычный интернет восстановился, и используй раздел ниже.

Доступность из конкретной сети с белыми списками проверяется только в этой сети. Короткий успешный тест на другом подключении и готовность 10/10 такой проверки не заменяют. Длительная стабильность и одновременная работа нескольких Mac пока не подтверждены.

## Если не получилось

| Что происходит | Что проверить |
| --- | --- |
| Не найден файл пакета | Все восемь файлов лежат в одной папке `~/Media-Test-10-private`, без лишней вложенной папки и расширения `.txt`. |
| Ошибка прав `bootstrap.json` | Повтори блок шага 4 от своего пользователя. Если файл принадлежит другому пользователю, получи и распакуй архив заново под своей учётной записью. |
| Порт 19180 занят | Другой адаптер уже работает. Не запускай второй экземпляр вручную; передай владельцу текст ошибки. |
| Адаптер не готов за 135 секунд | Проверь обычный интернет при отключённом Happ. Попроси владельца проверить сервер и действительность bootstrap. |
| Установка прошла, но при включении Happ интернет пропадает | Сначала отключи Happ. Проверь все исключения из шага 5, состояние Xray TUN и выбор именно профиля MUX. |
| Happ не принимает JSON | Скопируй весь файл `Media Test 10.json`, а не имя файла, ссылку или шаблон. Попроси владельца проверить пакет. |
| macOS не разрешает запуск бинарника | Получи у владельца доверенную совместимую сборку или помощь со сборкой из исходника. Установщик не отключает защиту macOS. |
| Раньше работало, теперь не подключается | Настройки редакторов, их версия или адреса могли измениться. Нужен свежий пакет; многократный перезапуск не обновляет токены. |

Владельцу можно передать текст ошибки установщика. Не публикуй содержимое `bootstrap.json`, ключа, профиля или полного журнала: там могут быть приватные данные.

## После перезагрузки и обновление

После входа в macOS адаптер запускается автоматически. Дай ему время подключиться к документам, затем включай выбранный профиль в Happ. Папка приватного пакета нужна для переустановки и ручного импорта профиля; работающий адаптер использует собственные копии в Application Support.

Обновления подписанных настроек автоматически не скачиваются. Свежий пакет выдаёт владелец VPN после проверки документов и сервера. При обновлении старой установки документы и ключ должны совпадать; установщик останавливается при несовпадении. Не смешивай файлы разных пакетов.

## Владельцу VPN: как заново собрать приватный пакет

Этот раздел выполняется **на старом настроенном Mac**, а не на новом. Нужен действующий сервер и уже проверенное подключение. Он не создаёт сервер, документы или токены заново.

1. В Терминале создай в домашней папке закрытую папку для пакета:

```sh
mkdir -m 700 "$HOME/Media-Test-10-private"
```

Если папка уже существует, сохрани прежний пакет под другим именем и создай новую пустую папку. Не смешивай пакеты и не помещай их внутрь Git-репозитория.

2. Открой в Finder через **Shift + Cmd + G**:

```text
~/Library/Application Support/Media Test 10/
```

3. Скопируй в новую папку **только четыре файла**: `media-adapter-msr`, `documents.urls`, `stream-relay.key`, `bootstrap.json`. Не копируй весь каталог с журналами и резервными копиями. Ключ — исходный двоичный файл, не скопированная текстовая строка.
4. Из каталога `client/macos/` этого репозитория скопируй туда `install.py` и `install.command`. Удобно скачать репозиторий через **Code → Download ZIP** и распаковать.
5. В Happ открой меню **проверенного Media Test 10 MUX** и выбери **Скопировать JSON сервера**. Сохрани скопированный текст через TextEdit в формате **обычного текста** под точным именем `Media Test 10.json` в новой приватной папке. Проверь, что расширение не стало `.json.txt`.

**Не бери старый `Media Test 10.json` из Application Support автоматически:** там может сохраниться исходный профиль без MUX. Проверенный профиль нужно экспортировать из Happ отдельно.

6. Выполни следующий блок в Терминале. Он проверяет MUX, убирает пути журналов старого пользователя из профиля и создаёт файл исключений по `dialAddress`. Токены и ключи в окно Терминала не выводятся.

```sh
python3 - <<'PY'
from pathlib import Path
import ipaddress
import json
import os

os.umask(0o077)
folder = Path.home() / "Media-Test-10-private"
folder.chmod(0o700)
profile_path = folder / "Media Test 10.json"
profile = json.loads(profile_path.read_text())
primary = [o for o in profile.get("outbounds", []) if o.get("tag") == "primary"]
if (len(primary) != 1 or primary[0].get("mux", {}).get("enabled") is not True
        or primary[0].get("mux", {}).get("concurrency") != 128):
    raise SystemExit("Нужен экспорт проверенного профиля Media Test 10 MUX.")
bundle = json.loads((folder / "bootstrap.json").read_text())
entries = bundle.get("documents", [])
if bundle.get("schemaVersion") != 1 or len(entries) != 10:
    raise SystemExit("Нужен актуальный bootstrap для десяти документов.")
addresses = set()
for entry in entries:
    try:
        address = ipaddress.ip_address(entry.get("dialAddress", ""))
    except (TypeError, ValueError):
        raise SystemExit("В bootstrap отсутствует корректный dialAddress.") from None
    if address.version != 4 or not address.is_global:
        raise SystemExit("Нужны проверенные публичные IPv4 в dialAddress.")
    addresses.add(address)
profile["remarks"] = "Media Test 10 MUX"
profile["log"] = {"loglevel": "warning", "access": "none"}
profile_path.write_text(json.dumps(profile, ensure_ascii=False, indent=2) + "\n")
profile_path.chmod(0o600)
routes = folder / "happ-excluded-routes.txt"
routes.write_text("".join(str(address) + "/32\n" for address in sorted(addresses)))
routes.chmod(0o600)
print("Профиль проверен; happ-excluded-routes.txt создан.")
PY
```

Если у записей нет `dialAddress` или настройки устарели, сначала обнови и проверь bootstrap на Mac и сервере по [техническому описанию](yandex-bootstrap.md). Не подставляй адрес или версию редактора наугад.

7. Убедись, что собраны восемь файлов из таблицы. В Finder нажми правой кнопкой на папке → **Сжать «Media-Test-10-private»**. Получится `Media-Test-10-private.zip`.
8. Передай архив владельцу нового Mac через AirDrop или USB. В GitHub отправляются только эта инструкция, исходники и шаблоны; приватный архив туда не загружается.

Установщик и его проверки описаны подробнее в [client/macos/README.md](../client/macos/README.md). Исходный результат проверки и ограничения находятся в [отчёте](status-2026-10-23.md).
