# Запуск транспорта Яндекс Документов с подготовленной конфигурацией

Существующий анонимный HTTP bootstrap больше не выдаёт `client-config`: сохранённые публичные ссылки открывают оболочку Диска. Обычный авторизованный браузер открывает редактор и получает необходимые подписанные настройки. Права редактирования десяти транспортных документов сохранились.

Восстановление использует явный параметр `--doc-bootstrap-file`. Файл содержит настройки, полученные при обычном открытии именно этих документов в редакторе. Он заменяет только получение начальной конфигурации страницы. Проверка TLS, допустимых адресов, WebSocket-аутентификация и шифрование relay сохраняются.

Флаг действует только вместе с `--stream-relay`; без него остаётся исходный способ загрузки страницы. Пример клиентского запуска после подготовки собственных приватных файлов:

```sh
media-adapter-msr --client --stream-relay \
  --url-list-file /private/path/documents.urls \
  --stream-key-file /private/path/stream-relay.key \
  --doc-bootstrap-file /private/path/bootstrap.json \
  --min-ready 10 --ready-timeout 120s --socks5 127.0.0.1:19180
```

Остальные параметры следует согласовать с сервером и существующим LaunchAgent. На серверной стороне используется такой же флаг и настройки для того же множества документов. Порядок ссылок может различаться: конфигурация сопоставляется по точному URL.

## Формат приватного файла

```json
{
  "schemaVersion": 1,
  "documents": [
    {
      "url": "https://disk.yandex.ru/i/EXAMPLE_ONLY",
      "editorUrl": "https://docs.yandex.ru/edit/d/EXAMPLE_ONLY",
      "dialAddress": "PUBLIC_BALANCER_IPV4",
      "clientConfig": {
        "officeActionData": {
          "editor_config": {},
          "balancer_url": "https://example.onlyoffice.disk.yandex.net",
          "version": "VERIFIED_EDITOR_VERSION"
        }
      }
    }
  ]
}
```

Это иллюстрация структуры, а не рабочая конфигурация. `editor_config` должен содержать исходные подписанные настройки соответствующего документа, включая JWT, `document.key`, адрес и тип файла, разрешения и заголовок. Подписанные поля нельзя менять или придумывать. Остальные поля корневого `client-config`, cookies и пароль аккаунта не требуются.

`officeActionData.version` — необязательные метаданные вне подписанного `editor_config`. Вместо `VERIFIED_EDITOR_VERSION` укажите точную версию из фактически загруженного ресурса редактора, проверенную в обычной браузерной сессии, например из пути ресурса, на который ссылается `/web-apps/apps/api/documents/api.js`. Парсер принимает формат из четырёх цифр года, двух числовых частей через точки и номера сборки после дефиса. Не подставляйте предполагаемую или случайную версию. Если конфигурация не содержит готового WebSocket-адреса, подтверждённая версия позволяет построить его без отдельного HTTP-запроса к API-ресурсу. Без этих метаданных сохраняется обычное обнаружение версии; JWT и подписанные поля остаются исходными.

Загрузчик ограничивает размер файла, число документов и размер каждой конфигурации, отвергает дубли, неизвестные или отсутствующие ссылки. Внешние адреса проходят ту же проверку, что и конфигурация обычной страницы. `editorUrl` является справочным полем: клиент по нему не переходит.

## Привязка адреса и исключение из Happ

`dialAddress` — необязательная строка с числовым публичным IP балансировщика из `officeActionData.balancer_url`. Вместо `PUBLIC_BALANCER_IPV4` нужен проверенный актуальный адрес этого узла. Привязка применяется отдельно к записи с точным `url`, независимо от порядка документов, и только к исходному имени балансировщика на порту 443. Она действует для HTTP и WebSocket; URL, HTTP Host, TLS SNI и проверка сертификата сохраняют исходное имя. Другие имена и порты используют обычное подключение. Cookies, глобальный DNS, hosts и общий HTTP-транспорт не меняются. Частные, локальные, multicast, неопределённые и специальные адреса отвергаются. Без `dialAddress` остаётся обычное разрешение DNS; поле можно удалить из примера целиком.

На macOS публичный IPv4 балансировщика также должен быть исключён из TUN Happ как маршрут `PUBLIC_BALANCER_IPV4/32` в исключениях PacketTunnel (`excludedRoutes`). Соединение к этому адресу должно выходить через физическую сеть, иначе оно снова попадёт во внутренний VPN и создаст рекурсию. Одна привязка IP решает зависимость от DNS, но не заменяет исключение маршрута. Исключение должно действовать после включения Happ и при повторном подключении каналов.

Храните bundle вне репозитория в приватном каталоге. На Mac файл должен быть доступен только владельцу; на сервере — root и пользователю службы. Токены предоставляют доступ к транспортным документам. В GitHub публикуется только код обработки и пример структуры.

## Срок действия и обновление

В исследованных JWT отсутствуют `exp`, `iat` и `nbf`. Это не обещает бессрочную работу: Яндекс может изменить ключ документа, сервер редактора, права или действительность подписи. При таком отказе потребуется получить свежую конфигурацию обычным входом в редактор, заменить приватный bundle и перезапустить оба участника.

Публичный IP балансировщика и версия редактора тоже могут измениться. При смене узла заново проверьте его адрес, обновите `dialAddress` в соответствующих записях приватного bundle и исключение `/32` в Happ. При смене версии обновите метаданные только по реально загруженным ресурсам редактора. После обновления перезапустите участников и повторите проверку передачи данных с включённым Happ.

Автоматическое обновление авторизованной браузерной сессии здесь не реализовано. Стандартный frontend использует `/edit/api?m=mpfs/office_action_data` с действующей сессией и защитным ключом. Это не проверенный анонимный API. Требование аккаунта для публичных ссылок описано в [официальной справке Яндекса](https://yandex.ru/support/yandex-360/customers/disk/web/ru/share/sharing-to-me.html?lang=ru).

## Проверка результата

Готовность `10/10` означает только вход в редакторские каналы. Для проверки VPN нужно передать данные через обе стороны relay и внутренний профиль Xray, проверить фактическую загрузку и счётчики приёма/передачи. Проверка доступности при белых списках дополнительно требует подключения из соответствующей сети оператора.
