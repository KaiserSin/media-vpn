# Проверка Media VPN — 23 октября 2026

Короткая проверка **Media Test 10 MUX в системном VPN Happ прошла**. HTTPS-запрос вышел через собственный VPS в NL с TLS 1.3; файл 1 МиБ получен с HTTP 200 за 23,028 секунды. После проверки Happ отключён, обычный HTTPS отдельно проверен: HTTP 200. Профиль MUX выбран в Happ; прежний профиль сохранён.

Это подтверждает короткую передачу через Яндекс Документы с данного Mac. Длительная стабильность и доступность из конкретной сети оператора с белыми списками не подтверждены. Наблюдаемая скорость невысока; готовность 10/10 сама по себе не гарантирует передачу данных.

Итоговая системная проверка использовала стандартные сетевые маршруты Mac, без отдельного диагностического SOCKS. В профиле основной VLESS outbound передаёт транспорт через локальный OpenFlux. Обычный прямой VLESS/CDN вместо Яндекс-транспорта не использовался. Отдельный HTTPS trace сравнил фактический адрес выхода с адресом собственного VPS.

Проверка была ограничена 40 секундами с автоматическим отключением. Само скачивание завершилось до отключения. На выходе из проверочного процесса состояние было Disconnecting; последующая независимая проверка подтвердила Disconnected и доступность обычного интернета. Ошибок аутентификации и формата relay после теста не обнаружено. Счётчики retransmit ненулевые: канал требует повторных передач, и это влияет на скорость.

Один промежуточный HTTPS-тест прервался сном Mac, подтверждённым системным журналом. Его тайм-ауты не использованы как доказательство сбоя. Другой промежуточный тест MUX32 завершился ошибками HTTP/2; он не включён в число успешных серий. После выбора MUX128 проведены отдельные чистые проверки HTTP/1.1 и обычного HTTPS.

## Изменения

Анонимные публичные ссылки Яндекс Диска больше не возвращали конфигурацию редактора. Для десяти собственных транспортных документов подготовлен приватный bootstrap из обычного авторизованного редактора. Он установлен на Mac и VPS с явного согласия владельца и не входит в архив.

Исправлен cursor framing: префикс содержит фактическую длину декодированных байтов. Размер stream-блока уменьшен с 32000 до 1024 байт: большие сообщения текущий сервис не передавал. Допустимый предел сервиса точно не установлен.

Добавлены сопоставление bootstrap по точному URL и необязательный числовой адрес balancer. Проверенная версия редактора в неподписанных метаданных позволяет пропустить запрос API-ресурса при переподключении. Подписанные editor-поля не изменялись. Host, SNI и проверка TLS сохраняются. В Happ добавлено исключение точного адреса транспорта, чтобы внешний адаптер не попадал в собственный VPN.

В отдельном профиле **Media Test 10 MUX** включён `primary.mux.enabled: true` с `concurrency: 128`. Он объединяет логические запросы в меньшее число внешних потоков relay и сокращает служебные ACK. Значения проверены повторным чтением импортированного JSON. Это улучшило результаты нагрузки; точная причина прежних закрытий сессий не доказана. Ограничение сервиса по частоте сообщений остаётся гипотезой.

## Проверки исходника и ограничения

Для исправления bootstrap/dialAddress прошли полный Go-набор тестов, полный запуск с детектором гонок и сборки Linux amd64/macOS arm64. Для последующей диагностики разрывов прошли тесты и race-проверка затронутого пакета, а также обе сборки. Локальные HTTPS/WSS-тесты проверяют сохранение Host/SNI и отказ при недоверенном сертификате. Проверка экспорта не обнаружила известных приватных ключей, подписок, токенов и адресов транспортных документов.

Обычный профиль Media отдельно прошёл HTTPS и скачивание через основной WS и резервный CDN XHTTP. Эти результаты не используются для подтверждения маршрута Яндекс Документов.

Работа из сети конкретного оператора с белыми списками, UDP, IPv6, утечки DNS, длительная стабильность, несколько одновременно работающих устройств и мобильный клиент не проверены. Автоматического обновления подписанных editor-конфигураций нет; при изменении сессии, версии или адреса редактора может потребоваться ручное обновление приватного bundle и исключения маршрута.
